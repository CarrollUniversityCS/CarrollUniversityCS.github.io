Wisconsin election-night benchmarks

What final margin would each of Wisconsin's 72 counties need to show for the 2026 Governor race to be tied, or D+3, or R+3 statewide? Set any statewide margin below and read off every county. The numbers were frozen and hashed before the election, and will be scored against certified results.

Not a forecast. A benchmark says what a county would need to show for a given statewide result. It does not say who will win. Public release: Sunday, November 1, 2026, 6 PM Central.

Compare complete counts only. A benchmark describes a place's final margin. Partial counts can mislead, because which ballots are counted first depends on how each municipality organizes its count. The typical deviation is history, not a limit: it is how far each county's final margin landed from its benchmark across nine tests against past elections (the older tests include 2016, which was far wider than recent years).

Frozen before the election

The method, the county, municipality and district tables, the pass line and the list of public forecasts to compare against were fixed and hashed on 2026-10-30 4:03 PM CDT. Any change after that is published as a dated erratum, never as an edit. The freeze is recorded in the project's version history as commit 753cbe55762be22924d7de319aa6f3712893001e.

How it was checked

  • A second program, written by a separate process that was not shown the first program's code, reproduces 87,170 published numbers: vote counts exactly and everything else to one part in a million. Both followed one written specification, so this catches errors in the code, not in the method.
  • A fresh rebuild from the raw files ran 20 steps and 144 tests on 2026-10-30 and changed 0 published files.
  • Every county table is cross-footed against the Wisconsin Elections Commission's printed statewide row.
  • Source code is not yet public.
