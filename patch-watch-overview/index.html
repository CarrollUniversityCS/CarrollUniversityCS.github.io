How fast do local government websites install security fixes?

When a software maker publishes a security fix, it only protects a website once someone installs it. Patch Watch measures how long that takes for Wisconsin's town, county, school-district and state websites, from the outside, without touching anything.

The short version

The question

After a serious security fix is published, how many days pass before government websites are protected, and which kinds of sites wait longest?

The method

Once on each snapshot day we ask each site for its public front page, the same way a browser does, and read the software label the page sometimes shows. Then we count groups of sites.

Why it matters

The time between "fix published" and "fix installed" is when a known weakness stays open. Knowing how long it lasts helps point help to the places that need it. Small public-sector sites are measured far less often than large companies.

The window we measure

A fix existing is not the same as a fix being installed. Every site sits somewhere in the gap between the two. Patch Watch measures how long that gap lasts across many sites.

How one measurement works

  1. Start with a public listThe official public list of .gov website names.
  2. Check the name existsAn ordinary name lookup. It goes to name servers, never to the website.
  3. Ask onceOne ordinary request for the front page, from a tool that identifies itself as this study.
  4. Read the labelSome pages announce their software version. We read only what the page chooses to show.
  5. Count groupsSites are sorted into classes and counted in groups. No site is named or ranked.

We never log in, never try exploits, never scan other doors, and never request any page except the front page. If HTTPS will not connect at all, we make one plain-HTTP attempt so we can tell "no site here" from "site refusing a secure connection".

What we can and cannot see

Seeing a version label is informative. Not seeing one proves nothing: the site may hide it, sit behind a protective service, or have been fixed without its label changing. That is why Patch Watch never counts "no label" as "patched".

Hidden on purpose

Many careful sites hide their version. Unknown, not safe or unsafe.

Fixed without a new label

Some providers copy a fix into an older version. We call that "possibly fixed" and say why.

Refused or errored

If a site refuses us or errors out, it is "not measured" and left out of every total.

Why you can trust the method

Plan written first

The analysis was pre-registered and frozen on October 23, 2026, before any live data existed. Later changes are logged in dated amendments, not edited in.

Ethics checked

On October 23, 2026 the chair of Carroll's Institutional Review Board confirmed that the work involves no human subjects and needs no IRB review.

Light touch

One ordinary front-page request per site per snapshot day, a declared study user agent, strict rate limits, no cookies and no logins.

Safety stop

The run halts on an abuse complaint or when sites start refusing or overloading, so a problem stops the study, not the site.

Groups, not names

Results are aggregate. No site is named or ranked, and small counts are suppressed by rule.

Checkable

The site list is pinned to one registry version, every request is written to a ledger, and the code has an automated test suite that runs on every update.

Opt out, no questions asked

Email jforden@carrollu.edu with your domain and it is removed within 24 hours, before we reply. Or block the CarrollPHPStudy/1.0 user agent at your firewall. A site that refuses us is recorded as "not measured", never as "vulnerable". Full notice: github.com/JForden/JForden.

It can tell you

  • How quickly groups of sites moved to a fixed version after a fix was published.
  • Which kinds of sites, such as towns, counties or election offices, tend to be faster or slower.
  • How much of a slow response comes from one hosting provider's upgrade schedule.
  • How Wisconsin's response compares with neighbouring states and with a 2024 benchmark.

It cannot tell you

  • Whether any one site is safe or unsafe. Results are never about a single site.
  • That a site with no visible version is patched.
  • A national estimate. Other states are added in waves and are not a representative sample.
  • Why a site updated or did not. The study observes timing, not reasons.
